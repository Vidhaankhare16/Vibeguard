What makes it different

Not just another linter.
An extraordinary audit.

Traditional tools were built before AI coding existed. VibeGuard is built for the patterns AI actually produces.

🔍

Cross-file taint analysis

Tracks untrusted data from every entry point — HTTP params, request bodies, env vars — through your entire codebase to dangerous sinks like SQL queries, shell commands, and file writes.

Taint path detected
// Entry: GET /api/orders/:id
req.params.id  ← untrusted
  → router.js:23
  → orderService.js:87
  → db.query(`SELECT * WHERE id = ${id}`)
⚠ SQL injection — no ownership check
🤖

AI pattern signatures

A database of known-bad patterns AI models produce repeatedly across unrelated projects. Mass assignment, algorithm confusion, unsafe deserialization — caught before they ship.

📦

Slopsquatting detection

AI tools hallucinate package names. Attackers register them. VibeGuard verifies every dependency against registries, checks download anomalies, and flags suspicious new packages.

🕰️

Git history secrets

A secret deleted from your codebase still lives in git history. VibeGuard scans every commit, including dangling objects from force pushes, and verifies whether found credentials are still active.

💉

Prompt injection mapping

For apps that integrate LLMs, VibeGuard maps every path where user-controlled data flows into a prompt without sanitization — the #1 vulnerability in OWASP's LLM Top 10.

📊

Reports built for developers

Not a wall of CVE IDs. Every finding includes a CVSS score, the exact taint path, and a copy-paste ready fix. Exported as JSON for CI/CD and a shareable Markdown report.

How it works

Three steps to a full audit

01

Install & run

No config files. No accounts. No setup. Point it at your project directory and it figures out the rest — language, framework, dependencies, git history.

$ npx @vidhaankhare/vibeguard scan .
02

Deep analysis runs

VibeGuard performs 4 phases of analysis in parallel — supply-chain hallucination detection, AST call-graph mapping, prompt injection boundary audit, and secrets scanning.

03

Get your report

A prioritized security report with CVSS scores, taint paths, and copy-paste fixes. Exported as JSON (for CI/CD) and Markdown (for your team). Security score included.

Install

Run anywhere, zero setup

VibeGuard is an npm package. Run it instantly with npx, install it globally, or drop it into any CI/CD pipeline.

npx

Run without installing

The fastest way to audit any project. No global install needed — npx pulls the latest version automatically.

$ npx @vidhaankhare/vibeguard scan .
global

Install globally

Install once and run vibeguard from any project directory on your machine.

$ npm install -g @vidhaankhare/vibeguard
$ vibeguard scan .
CI/CD

GitHub Actions & pipelines

Drop into any CI pipeline with --yes to skip interactive prompts. Works in GitHub Actions, GitLab CI, and more.

$ npx @vidhaankhare/vibeguard scan . --yes
